# Практика SQL и PostgreSQL (Школа 21)

Репозиторий с практическими заданиями по работе с реляционными базами данных, выполненными в рамках обучения в «Школе 21». Демонстрирует навыки проектирования баз данных, написания сложных запросов, манипулирования данными и оптимизации производительности на PostgreSQL.

## Стек

- PostgreSQL
- ANSI SQL

## Изученные темы и навыки

- **Сложные выборки (Retrieving Data):** Множественные соединения таблиц (INNER, LEFT, RIGHT, FULL), подзапросы, CTE (WITH), операции над множествами (UNION, EXCEPT, INTERSECT).
- **Манипуляция данными (DML) и DDL:** INSERT, UPDATE, DELETE, создание таблиц, добавление ограничений (Primary/Foreign Keys, CHECK, UNIQUE) и работа с последовательностями.
- **Представления и материализация:** Создание виртуальных и материализованных представлений (Views, Materialized Views), обновление данных и управление схемой.
- **Оптимизация запросов:** Создание B-Tree индексов (простых, функциональных, многоколоночных, уникальных, частичных), анализ планов выполнения (`EXPLAIN ANALYZE`) и повышение производительности.
- **Аналитика данных (OLAP):** Агрегация, оконные функции, GROUP BY, HAVING, генерация временных рядов и расчет бизнес-метрик.
- **Продвинутые задачи:** Решение задачи коммивояжера (моделирование графов и рекурсивный SQL), интеграция новых бизнес-фич в существующую модель данных.

## Структура проекта

Репозиторий разделен на модули (SQLB1 – SQLB8), каждый из которых содержит папку `src/` со SQL-скриптами для конкретных заданий.
