# PostgreSQL Practice (School 21)

Repository containing practical SQL assignments completed during the School 21 bootcamp. It demonstrates proficiency in relational database design, complex querying, data manipulation, and performance optimization using PostgreSQL.

## Tech Stack

- PostgreSQL
- ANSI SQL

## Covered Topics & Skills

- **Complex Queries (Retrieving Data):** Multi-table joins (INNER, LEFT, RIGHT, FULL), subqueries, CTEs (WITH), set operations (UNION, EXCEPT, INTERSECT).
- **Data Manipulation (DML) & DDL:** INSERT, UPDATE, DELETE, creating tables, adding constraints (Primary/Foreign Keys, CHECK, UNIQUE), and working with sequences.
- **Views & Materialization:** Creating standard views and materialized views, refreshing data, and managing schema.
- **Query Optimization:** Creating B-Tree indexes (simple, functional, multicolumn, unique, partial), analyzing execution plans (`EXPLAIN ANALYZE`), and improving performance.
- **Data Analytics (OLAP):** Aggregations, window functions, GROUP BY, HAVING, generating time series, and calculating business metrics.
- **Advanced Tasks:** Solving the Traveling Salesman Problem using graph modeling and recursive SQL, integrating new business features into an existing data model.

## Project Structure

The repository is organized into modules (SQLB1 through SQLB8), each containing `src/` folder with SQL scripts for specific tasks.
